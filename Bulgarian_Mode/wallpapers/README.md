# Bulgarian Mode wallpapers

The original files were 275×183 web thumbnails (7–17 KB), stretched ~7× to fill
a 1080p screen — that was the "pixelated" look. These are 2560-px versions made
with Real-ESRGAN (`RealESRGAN_x4plus`, one 4× pass, then Lanczos to 2560 wide),
which reconstructs texture instead of interpolating pixels; a second 4× pass was
tried and rejected (over-sharpened, painted-looking).
